python3 cycle.py --publish --limit 5

reports another run is active, leave that run alone. Do not modify the code or

through this command. Never send demonstration drafts or arbitrary test posts.

output/drafts.txt. The SQLite database at AI_NEWS_DATABASE_PATH is the durable

not an English name, number, emoji or punctuation. This is recorded in
writing-prompt.txt and enforced by text_rules.py before drafting and sending.
Use AGENTS.md and docs/product.md for project requirements. Writing instructions are loaded from
writing-prompt.txt on every inference call; chat history is not passed to it.

not register or activate a schedule.
